# Buttons

| Type | Use | Style |
|---|---|---|
| CTA | Start something: "Get started", "Buy now" | Filled primary, optional shadow, the biggest button |
| Primary | Move forward: "Continue", "Save", "Next step" | Filled |
| Secondary | Alternatives: "Back", "Cancel", "Edit" | Outline, or transparent (a light tint background) |
| Tertiary | Situational actions: share, bookmark | Text link or small button |

- **One primary per group.** Importance equals visibility.
- **Size:**
  - Height 40–60 px, never below 40.
  - Label 16 px, never below 13 or above 20.
  - On web, horizontal padding of about 32 px and width follows the label.
  - On mobile, full width minus the margins (in 99% of cases).
- **States:** default, hover, pressed, focus, disabled. A disabled button has no shadow.
- **Pairs:** the more important button goes on the **right**. The first step of a flow has no "Back".
- **Icons in buttons** help scanning. Icon-only buttons are only for icons you have seen in other mainstream products.
- **Very Important Buttons:** when the action takes something from the user (money, data):
  - The label must be explicit: "Complete purchase", not "Continue".
  - Add a note below it, such as "Your card will be charged $X."
