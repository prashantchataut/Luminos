# Cards

- **A card is a short version of a page.** It helps users decide what to open. Show only the information that drives that decision. A recipe card, for example, shows the photo, title, time, servings and difficulty, but not the ingredients.
- **Typical anatomy:** image, an icon action (such as a heart), title, short text, key data (such as a price), and a CTA only if it is useful.
- **Make it look clickable:**
  - A subtle shadow lifts it off the background.
  - On hover, the card and its shadow grow slightly (a small scale-up).
- **Default style:** a white fill with a soft shadow. Alternatives are a border, or a fill slightly darker than the background. **Never mix card styles in one product.**
- **Handle edge cases:**
  - Truncate long titles and descriptions with an ellipsis, using character or line limits.
  - Show a placeholder when there is no image.
  - Define variants per breakpoint.
