# Icons

- **Icons replace reading,** so being understood matters more than looking pretty. There are two kinds:
  - **Interactive icons** behave like buttons. They must be simple and familiar: home, search, favorites, profile, settings.
  - **Clarifying icons** explain a category or feature and may carry more detail.
- **Use one icon pack.** Don't draw icons yourself or mix packs. Examples: Feather (free), Streamline, Iconly. **(convention)** Lucide is a maintained fork of Feather.
- **Use a line style or a filled style.** The only allowed mix is in the nav: a filled icon for the selected item and line icons for the rest.
- **Consistency:** the same stroke width and the same corner roundness throughout. Sharp corners read as formal, rounded ones as friendly.
- **Sizing:**
  - Put each icon in a bounding box (usually 24×24) and resize the box, not the glyph.
  - The tap area is at least 44×44, which is bigger than the box.
- **Labels:** label any icon that isn't universally known. When in doubt, add the label.
- **Optional matching:** match the icon stroke to the label's font weight, but only if the set's stroke doesn't have to change.
