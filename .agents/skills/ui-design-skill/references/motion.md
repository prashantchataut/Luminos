# Motion and microinteractions

- **A microinteraction is feedback** for a user action, so the user knows it worked. Examples: a switch or checkbox toggling, a like going from outline to filled, a tab icon changing, a button hover, a "sent" confirmation, a spinner or skeleton while loading.
- **Short and subtle:** under 1000 ms. Never make an animation longer just to show it off.
- **Eased, not linear:** real objects speed up and slow down.
- **No flashy 3D or showcase-style animations** in real products. They are hard to build and slow the device.
- **Nothing flashes more than 3 times per second** (epilepsy risk).
- **(convention)** Respect `prefers-reduced-motion`.
