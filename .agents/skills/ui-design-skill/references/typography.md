# Typography

## Choosing a typeface

- **Choose for function and brand:** readable (simple shapes), scalable (works tiny and huge), with many weights, and in line with the brand's personality.
- **Sans serif is the default.** Serif fits long-form reading or a serious brand. **Never use a script or handwritten face** for UI text.
- **One typeface.** If you must pair two, make them clearly different (Inter + Gelasio works; Raleway + Poppins is too similar).

## Size and length

- **Body size:** 16–17 px. Never shrink text to fit more content.
- **Line length:** 50–60 characters for body text (70 is too long). In CSS: `max-width: 60ch`.

## Alignment

- **Left-align** for left-to-right languages.
- **Center** only short text, such as headings and one-line blurbs.
- **Right-align** only for right-to-left languages.

When you control the copy, avoid ragged line ends in long paragraphs (one long line followed by a very short one).

## Weight

- **Headings are heavier than body text,** and larger sizes get heavier weights. The book's example: 12 Regular, 14 Regular, 16 Medium, 18 SemiBold, 20 Bold.
- **Skip a weight or two** between the body weight and the header weight: Regular body with a Bold header, not Regular with Medium.
- **Use at least Regular.** Use Light only at large sizes, as an experiment.
- **Tiny text:** use SemiBold, optionally in uppercase with +5% letter spacing.
