`improve-ui` says "strictly read-only on product source". This task explicitly asked for code changes, so the audit below was done first on the v4.1 renders and source, then the fixes were made. The audit is not a full skill run.

## Audit of the v4.1 launcher (traced path: App.tsx > Sidebar > Home / Mods / Cosmetics / Preferences)
1. **Sidebar** (228px, three group headings, 8 items, "Check for Updates" and "Quit Luminos" text buttons, a module counter badge). Grouping used headings AND space; Profiles duplicated Home's world list. Fixed: flat 7-item list, 220px, 36px pills, account + Quit only.
2. **Home**: a 330px hero carried a decorative stat pill ("Sodium + Lithium + ImmediatelyFast ready, Native Max FPS") that states a fact nobody measured, plus two cover cards that only repeated the version menu. Fixed: pill and cards removed, hero 300px, one primary action "Launch <version>".
3. **Mods**: 3-column cards with glow bar, switch, gear, a blurb and up to three live-value pills (dense, inconsistent card heights). Fixed: 4 columns, one 40px icon, name, a full-width 38px bar that is the switch (cobalt / slate), gear top right.
4. **Capes**: already capes-only (no preset skins). Left preview + 3-column capes grid kept. Remaining issue: the 3D preview is dark in the software-GL render (SwiftShader lighting), not changed.
5. **Preferences**: four tabs, 68px rows with no icons, a RAM slider up to 16 GB defaulting to 4 GB. Fixed: single column of 62px rows with icons, RAM 1-3 GB default 2 GB with a "Free System RAM" readout, the old tabs live under "Advanced".
6. **Contradiction found in the render**: sidebar said "Fabric 26.3" while the hero said 1.21.11. Fixed by dropping the version from the account chip.
7. **Misleading control found in round 1**: "Performance Engine" switch showed OFF by default (it is the Max FPS profile; default is Balanced). Subtitle now says what on/off mean.
