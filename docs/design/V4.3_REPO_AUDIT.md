# v4.3 repo audit

Inputs read: `git log -n 6 --stat`, GitHub Actions runs, the releases API, the five skills (`improve-ui`, `better-layout`, `better-motion`, `taste-skill`, `audit-ai-design-slop`) and every `*-3.png` from v4.2 viewed as an image.

## What the previous session shipped or broke
- **Release pipeline was broken.** Both `Release Luminos` runs for `v4.2.0` failed in `publish` at "Gather, checksum, notes": `scripts/release-notes.mjs` rejects a CHANGELOG section without `### English` and `### Español`. `releases/latest` is still **v4.1.0**; 4.2.0 never shipped. All other 4.2.0 jobs (client jars, Windows, Android, CI, tests, smoke) were green.
- **Screenshots were from three eras.** `home/mods/cosmetics/preferences-3` were re-rendered in 4.2. `hud-studio/keybinds/themes-3` still showed the pre-4.2 grouped sidebar with "Profiles", "Cosmetics" and "Fabric 26.3", plus a different logo. `ingame-titlescreen-3` is the 4.1.0 offscreen render.
- **Config sync was one-way and partial.** The launcher overwrote the whole `config/luminos/config.json` (erasing the game's `hud` block); the game read only `modules` and `hotkeys` once at start; HUD positions and the cape never reached the game; no `load_client_config` / `save_client_config` commands.
