# Skins and capes: sources, what we took, what we did not (session 15)

Written from requests made on the day (2026-11-24), not from memory. Where a source blocked or forbade copying, we link to it.
Script and cache dates are in the files named below. Rule applied everywhere: **if the licence or permission is unclear, we do not ship it; we link to it.**

## 1. Source-by-source

| Source | What we checked | Result | What Luminos does |
|---|---|---|---|

| **minecraftskins.com** (a different site from MC-Skins.net) | `robots.txt` | Allows crawling except `/skin/download/`, `/search/author/`, `/actions/` and query URLs; we found no licence that lets us redistribute the skins, and many are tied to personal accounts. | **Not copied.** Not linked from the app (we linked MC-Skins.net instead, as briefed). |

## 2. What we shipped

| Set | Count | Origin | Licence |
|---|---|---|---|
| Luminos skins | **48** (8 each: survival, pvp, builder, cute, spooky, minimal) | Generated by `tools/make_skin_library.py` from rectangles and an ordered dither. No third-party texture was read, traced or recoloured. | CC0-1.0 |
| Luminos capes | **14** (8 static, **6 animated**: shimmer, aurora, live coals, beacon, night sky, banner) | Same generator. Animated capes are vertical frame strips (`64 x 32n`) with `frames` and `frameMs` in the manifest. | CC0-1.0 |
| Community skins | **0** | See section 1: the two catalogues the brief named are blocked or reserve rights. | n/a |
| Mojang / OptiFine / LabyMod capes | live lookup only | capes.dev | not redistributed |

Files: `app/public/library/skins/*.png`, `app/public/library/capes/*.png`, manifest `app/src/data/library.json`, one licence row per file in `docs/research/LIBRARY_ATTRIBUTION.md`, contact sheet `docs/research/library-contact-sheet.png`.

**Gap against the brief:** the brief asked for "at least 40 original skins plus the top ~200 community skins". The 40+ original skins are done (48). The 200 community skins are **not**, and cannot be done lawfully from the sources named. A lawful route would be asking creators on a licensed hub (for example OpenGameArt entries explicitly marked CC0/CC-BY) or running a submission process with a licence checkbox; neither was started.

## 3. Caches and rate limits

- `tools/fetch_launcher_cache.py` snapshots public server status (api.mcsrvstat.us, 5 requests, 1.5 s apart) and Mojang patch notes (1 request) into `app/src/data/servers-cache.json` and `news-cache.json`. User-Agent names the project. No personal data.
- Modrinth icons for 6 projects (VulkanMod, Nvidium, C2ME, ModernFix, Exordium, Iris) were fetched once with the public API and a project User-Agent into `app/public/mods/`; project licences are LGPL-3.0 / GPL-3.0 per the API response, and the icons are used only to identify the project in the launcher.
- Nothing in the repo contains a player's skin, UUID or name beyond the demo account name "Mira".

## 4. How other players see these (honest limits)

- **Official online-mode servers are Mojang-authoritative.** A launcher cannot change the skin or cape other players see there.
- **Third-party capes render only for people with the matching provider** (OptiFine, LabyMod, SkinMC, or the Luminos mod). The **Offline view** badge on the Cosmetics viewer says this on screen.
- The Luminos-cape model mirrors SkinMC Custom Capes: a user-uploaded cape fetched by UUID from a provider endpoint. **The Luminos provider server was not built** (the brief forbids new server-side features), so today Luminos capes are visible to the wearer only.
